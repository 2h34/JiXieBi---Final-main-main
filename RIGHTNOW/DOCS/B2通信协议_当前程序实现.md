# B2 主控与机械臂副板通信协议（当前程序实现）

> 本文档依据 `tongxin-try-rzg` 当前源码整理，描述程序目前真实执行的通信行为。
>
> 当前版本日期：2026-08-30  
> 当前可用范围：单机械臂左臂版本

## 1. 通信参数

- 通信总线：CAN1
- 波特率：1 Mbps
- 帧格式：29 位扩展数据帧
- 主控发送 ID：`0x010105xx`
- 副板反馈 ID：`0x050101xx`
- `xx` 为操作码

CAN1 同时连接 DJI 电机。DJI 使用标准帧并进入 FIFO0；主控扩展帧进入 FIFO1，由软件继续检查扩展 ID 前缀。

## 2. 通用反馈格式

动作反馈的 DLC 为 2：

```text
Data[0] = 执行状态
Data[1] = 原命令操作码
```

| Data[0] | 含义 |
| --- | --- |
| `0x00` | 已接收，准备开始执行 |
| `0x01` | 执行完成 |
| `0x02` | 拒绝，当前忙或未使能 |

例如左臂取块：

```text
主控发送：0x01010503
副板接收：0x05010103  [00 03]
副板完成：0x05010103  [01 03]
副板拒绝：0x05010103  [02 03]
```

副板接收动作命令后先回复“已接收”，随后由 5 ms 任务执行动作；对应状态机真正完成后，再回复“执行完成”。

## 3. 查询 `0x00`

### 主控发送

```text
ID  = 0x01010500
DLC = 0
```

### 副板回复

```text
ID  = 0x05010100
DLC = 2
```

| 回复数据 | 含义 |
| --- | --- |
| `02 00` | 机械臂未使能 |
| `01 01` | 已使能，但机械臂正在归零或移动 |
| `00 01` | 已使能，机械臂可以接收动作 |

第二字节的 bit0 表示使能状态：

```text
bit0 = 0：未使能
bit0 = 1：已使能
```

当前 Busy 只包含以下 BlockArm 状态：

```text
BLOCK_ARM_HOMING
BLOCK_ARM_HOME_TO_SAFE
BLOCK_ARM_MOVING
```

吸盘正在吸取、释放，或者 Place 正在等待释放命令时，查询结果不一定显示 Busy。主控应以动作 FINISH 作为任务流程的主要判断依据。

## 4. 使能与失能 `0x01`

### 4.1 使能

主控发送：

```text
ID   = 0x01010501
DLC  = 2
Data = [01 00]
```

副板立即回复：

```text
ID   = 0x05010101
DLC  = 2
Data = [01 00]
```

随后副板执行：

```text
BlockArm_Enable()
→ BlockArm_Home()
→ DJI与ZDrive机械归零
→ 移动到归零后安全位置
→ BLOCK_ARM_READY
```

使能后不再主动发送归零完成帧。主控必须周期发送查询 `0x01010500`，直到收到：

```text
0x05010100  [00 01]
```

### 4.2 失能

主控发送：

```text
ID   = 0x01010501
DLC  = 2
Data = [00 00]
```

副板回复：

```text
ID   = 0x05010101
DLC  = 2
Data = [00 00]
```

随后副板执行：

```text
BlockArm失能
→ 关闭吸盘
→ Pick Task回IDLE
→ Place Task回IDLE
→ 清除旧FINISH记录
```

## 5. 左臂取块 `0x03`

### 主控发送

```text
ID  = 0x01010503
DLC = 1
```

| Data[0] | 目标 |
| --- | --- |
| `0x00` | 低位取块 |
| `0x01` | 高位取块 |

### 执行流程

```text
移动到取块姿态
→ 到位
→ 等待约1秒
→ 自动启动吸盘
→ 吸取计时完成
→ 移动到通用安全位置
→ Pick Task进入DONE
```

### 反馈

```text
已接收：0x05010103  [00 03]
已完成：0x05010103  [01 03]
拒绝：  0x05010103  [02 03]
```

当前 Pick 为自动吸取，不需要主控发送 ConfirmGrab。

## 6. 左臂移动到放块位置 `0x04`

### 主控发送

```text
ID  = 0x01010504
DLC = 1
```

| Data[0] | 目标 |
| --- | --- |
| `0x00` | 底层放置位置 |
| `0x01` | 第一层放置位置 |
| `0x02` | 第二层放置位置 |

### 执行流程

```text
移动到放块姿态
→ 到位
→ Place Task进入MANUAL_ALIGN
→ 保持当前位置
→ 等待主控发送0x07
```

### 反馈

```text
已接收：0x05010104  [00 04]
已到位：0x05010104  [01 04]
拒绝：  0x05010104  [02 04]
```

`[01 04]` 只表示机械臂已经到达放块位置，不表示物块已经释放。

## 7. 左臂释放 `0x07`

主控应在收到 `[01 04]`，并确认底盘已经移动到合适位置后发送释放命令。

### 主控发送

```text
ID   = 0x01010507
DLC  = 1
Data = [00]
```

当前程序只检查 DLC，不使用 `Data[0]`，主控固定发送 `0x00`。

### 执行流程

```text
释放吸盘
→ 等待释放计时完成
→ 移动到对应安全位置
→ Place Task进入DONE
```

### 反馈

```text
已接收：0x05010107  [00 07]
已完成：0x05010107  [01 07]
拒绝：  0x05010107  [02 07]
```

第二层放置结束后，机械臂先保持在二层专属安全位置。底盘移出后，主控可以发送 Reset，使机械臂返回通用安全位置。

## 8. 全机构复位 `0xFF`

### 主控发送

```text
ID   = 0x010105FF
DLC  = 2
Data = [R 00]
```

当前左臂版本支持：

| R | 含义 |
| --- | --- |
| `0x00` | 全部机械臂 |
| `0x01` | 左机械臂 |

### 执行流程

```text
停止Pick/Place
→ BlockArm返回通用Safe
→ 关闭吸盘
→ Pick Task回IDLE
→ Place Task回IDLE
```

### 反馈

```text
已接收：0x050101FF  [00 FF]
已完成：0x050101FF  [01 FF]
拒绝：  0x050101FF  [02 FF]
```

当前 Reset 在 BlockArm 处于 `HOMING`、`HOME_TO_SAFE` 或 `MOVING` 时会被 Busy 判断拒绝。

## 9. 错误命令 `0xEE`

当前程序收到 `0x010105EE` 后只回复：

```text
0x050101EE  [02 EE]
```

当前尚未根据错误类型执行具体故障处理。

## 10. 右臂预留协议

| 操作码 | 含义 |
| --- | --- |
| `0x05` | 右臂取块 |
| `0x06` | 右臂移动到放块位置 |
| `0x08` | 右臂释放 |

右臂 Reset 选择值：

```text
R = 0x02
```

当前 CAN 接收回调只启用左臂处理函数，因此 `0x05/0x06/0x08` 暂时不会执行。

右臂处理函数虽然已经按左臂格式补齐，但任务层 FINISH 仍固定使用左臂操作码：

```text
Pick完成    → 0x03
Place到位   → 0x04
Release完成 → 0x07
```

因此在启用右臂版本前，还需要把右臂完成反馈对应为 `0x05/0x06/0x08`。当前正式可用范围仍为单左臂。

## 11. 当前未实现的命令

```text
0x09～0x0C：夹爪命令
0x0D～0x0E：左右臂ConfirmGrab
```

## 12. 主控推荐执行顺序

```text
1. 发送Enable 0x01
2. 收到[01 00]
3. 周期发送Query 0x00
4. 收到[00 01]

5. 发送Pick 0x03
6. 收到[00 03]
7. 等待[01 03]

8. 发送Place 0x04
9. 收到[00 04]
10. 等待[01 04]

11. 底盘完成移动
12. 发送Release 0x07
13. 收到[00 07]
14. 等待[01 07]

15. 需要返回通用Safe时发送Reset 0xFF
16. 收到[00 FF]
17. 等待[01 FF]
```

## 13. 当前通信约束

当前副板只保存一个待执行命令 `Master_Command` 和一个完成记录 `s_finish_process`，因此：

- 主控一次只能发送一条动作命令。
- 主控必须等待当前动作 FINISH 后再发送下一条动作命令。
- 查询命令可以用于检查使能和机械臂移动状态。
- Place 必须按照 `0x04 到位 → 底盘移动 → 0x07 释放` 的两阶段流程执行。
- 即时“已接收”回复采用直接 CAN 发送，发送失败时当前不会重试。
- 最终 FINISH 发送失败时会保留完成记录，并在后续 5 ms 周期继续重试。
