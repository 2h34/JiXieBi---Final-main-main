### A-1 `Config/arm_config.h`（全新，唯一"左右差异源"）

```c
#ifndef ARM_CONFIG_H
#define ARM_CONFIG_H

#include <stdint.h>
#include <stdbool.h>

/* ---------- 左右臂编译宏：由 Keil 两个 Target 分别 Define ----------
 * f4_show_LEFT  →  Define: ARM_LEFT
 * f4_show_RIGHT →  Define: ARM_RIGHT
 */
#if defined(ARM_LEFT)
  #define ARM_SOLENOID_CHANNEL   1U          /* 当前左板值：solenoid_init(1)     */
  #define ARM_DJI_INDEX          0U          /* 当前左板值：&DJmotor[0]           */
#elif defined(ARM_RIGHT)
  #define ARM_SOLENOID_CHANNEL   2U          /* 当前右板值：solenoid_init(2U)    */
  #define ARM_DJI_INDEX          1U          /* 当前右板值：&DJmotor[1]           */
#else
  #error "Please define ARM_LEFT or ARM_RIGHT in Keil target defines"
#endif

#define ARM_ZDRIVE_INDEX         0U          /* 两板相同                        */

/* ---------- CAN 信号组（⚠ 保持现状交叉对应，待用户确认） ----------
 * 当前：左板工程启用 Master_message_handler_right → 响应 0x05/06/08
 *       右板工程启用 Master_message_handler_left  → 响应 0x03/04/07
 */
#if defined(ARM_LEFT)
  #define ARM_PICK_SIGNAL        0x05U
  #define ARM_PLACE_SIGNAL       0x06U
  #define ARM_RELEASE_SIGNAL     0x08U
  #define ARM_QUERY_SIGNAL       0x00U
  #define ARM_ENABLE_SIGNAL      0x01U
#elif defined(ARM_RIGHT)
  #define ARM_PICK_SIGNAL        0x03U
  #define ARM_PLACE_SIGNAL       0x04U
  #define ARM_RELEASE_SIGNAL     0x07U
  #define ARM_QUERY_SIGNAL       0x00U
  #define ARM_ENABLE_SIGNAL      0x01U
#endif

/* ---------- 7 姿态标定角表（原样搬自两边 BlockArm.c 实测值） ---------- */
typedef struct { float dji_deg; float zdrive_deg; } ArmPose_t;

/* 顺序必须与 BlockArm.c 内 BlockArmTarget_t 枚举一致：
 * LOW_PICK, HIGH_PICK, SECOND_PICK, PLACE_BOTTOM, PLACE_LEVEL1, PLACE_LEVEL2, SAFE */
extern const ArmPose_t ARM_POSES_LEFT[7];
extern const ArmPose_t ARM_POSES_RIGHT[7];

#endif /* ARM_CONFIG_H */
```

### B-3 `IRQ/Src/CAN_IRQHandler.c`（合并双 handler + 信号宏化 + 修正 FINISH 码）

**B-3.3 `Master_message_handler_left`（215-380 行）与 `right`（383-548 行）合并为单一 `Master_message_handler()`：**

两个函数唯一差异是 4 个 signal 常量，其余 90% 相同（0x00 查询 / 0x01 使能 / 0xFF 复位 / 0xEE 错误 / 点击记录 / 释放确认）。合并规则：

| 原 left 函数 | 原 right 函数 | 合并后 |
|---|---|---|
| `case LEFT_START_PICK:` | `case RIGHT_START_PICK:` | `case ARM_PICK_SIGNAL:` |
| `case LEFT_START_PLACE:` | `case RIGHT_START_PLACE:` | `case ARM_PLACE_SIGNAL:` |
| `case LEFT_CONFIRM_RELEASE:` | `case RIGHT_CONFIRM_RELEASE:` | `case ARM_RELEASE_SIGNAL:` |
| `case RESET:`(0xFF) | 相同 | 保留一份 |
| `case 0x00/0x01/ERROR(0xEE)` | 相同 | 保留一份 |

具体操作：删除 `Master_message_handler_left`，把 `Master_message_handler_right` 改名为 `Master_message_handler`，其中 4 处 `RIGHT_*` 常量替换为 `ARM_*_SIGNAL` 宏；`Comm_RecordClick`（120-140 行）保持不变。

**B-3.4 回调选择点（第 588-590 行）——消除"手动切换注释"：**
改前：
```c

/*如果在右臂上烧录代码，则把这个从注释里捞出来并注释掉上一句*/
```

```c
Master_message_handler(hcan, RxHeader, RxData);
```

**B-3.5 `Comm_RecordClick`（120-140 行）不变；`Comm_ClickProcess`（143-212 行）不变**（signal 判定在 handler 内已完成，点击记录用统一 signal）。
